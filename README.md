JavaScript Contact book 📖

Project Overview 

The Contact Book is a JavaScript application that allows users to manage a list of contacts. Users can add, view, search, update and delete contact information through a simple interface 

🎯Purpose 

The purpose of this project is to practice JavaScript fundamentals by building a practical that manages and manipulates data. It focuses on working with arrays, objects, functions, user input and basic CRUD operations. 

Tech stack 👩🏽‍💻

HTML5 – Provides the structure and layout of the application.
CSS3 – Used for styling and creating a clean, user-friendly interface.
JavaScript – Handles the application logic, contact management, user interactions, and CRUD operations.
DOM Manipulation – Used to dynamically display and update contact information on the page.

Features 

* Add new contacts
* View saved contacts 
* Search for a contact 
* Update existing contact information 
* Delete contacts 
* Store contact details such as : Name, Phone Number, Email address 
* Validate user input 
* Display clear messages when actions are completed or errors occur

How it works 
The application uses JavaScript to create and manage contact objects. 

1. The user selects an action from the available options 
2. Contact information is entered when adding or uploading a contact 
3. JavaScript stores the information in any array of contact objects 
4. Functions are used to search, update, display or remove contacts 
5. The application provides feedback to the user after each action 

The projects demonstrates basic CRUD functionality: 
Create - To add a new contact 
Read - View or search contacts 
Update - Modify existing contact details 
Delete - Remove a contact
